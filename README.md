# Project Steelhead (Unity)

* Jest to mój pierwszy samodzielny projekt w Unity, powstał jako projekt zaliczeniowy
* Projekt był wzorowany na grach z serii Dark Souls
* Skupiałem się na mechanikach gameplayowych, przez co brak w nim np. dźwięków, ustawień i tego typu innych rzeczy
* Projekt ma trochę błędów ponieważ po oddaniu jego na zaliczenie już nad nim nie pracowałem
